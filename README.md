# 2IRR00 Group Project: Modern Tetris Game



## Project Structure (Phase 1)

```
src/main/java/com/mycompany/irr00_group_project/
│
├── App.java
├── TetrisGameMain.java
├── EnhancedGameEngine.java
├── gameAnimation/         # Game loop, timing, rendering, controller
├── GUI/                   # User interface components
├── gamelogic/             # Core Tetris logic (grid, pieces, rules)
├── scoresystem/           # Score calculation and display
```

We put all our tests in `src/test/java/com/mycompany/irr00_group_project/`.
